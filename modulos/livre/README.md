# Modo Livre

Salvar, carregar, comparar e registrar — sem servidor, tudo no navegador.

- **Salvar**: cada módulo salva sua config (`FIS.store.save`). Aqui você lista tudo (`FIS.store.list`), carrega, exporta/importa JSON e monta **comparação A×B** (cole 2 JSONs e veja lado a lado).
- **Medições**: tabela + CSV (nome, valor, unidade, origem).
- Privacidade: localStorage do navegador. Compartilhar = enviar o arquivo JSON.
